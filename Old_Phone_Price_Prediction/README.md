# Old Phone Price Prediction 📱

A Machine Learning web application built with Python and Streamlit that predicts the **resale price of a used smartphone** based on its specifications, condition, and purchase details.

## Live Demo

🔗 **Try the app:** [Your Streamlit App Link](https://old-phone-price-predict.streamlit.app/)

## Project Overview

The Old Phone Price Prediction application allows users to enter details about a used smartphone and receive an estimated resale price.

The application uses a trained Random Forest Regression model to predict the resale value based on phone specifications, physical condition, and other relevant features.

## Features

- Select a smartphone brand and its corresponding model.
- Enter RAM, storage, battery capacity, and other specifications.
- Provide details about the phone's condition and physical damage.
- Include repair history and available accessories.
- Calculate ownership duration from the purchase month and year.
- Validate user inputs to ensure reasonable values.
- Predict the estimated resale price of a used smartphone.
- Interactive web interface built with Streamlit.

## Technologies Used

- **Python** — Programming language
- **Pandas** — Data handling and manipulation
- **NumPy** — Numerical computations
- **Scikit-learn** — Machine Learning, preprocessing, and model training
- **Joblib** — Saving and loading the trained model
- **Streamlit** — Web application interface

## How It Works

1. The user selects a smartphone brand and model.
2. The user enters the phone's specifications, condition, and purchase details.
3. The application validates the entered values and calculates ownership duration.
4. The input data is processed using the saved preprocessing pipeline.
5. The trained Random Forest Regression model predicts the resale price.
6. The application displays the estimated resale price.

## Model Information

- **Algorithm:** Random Forest Regression
- **Target Variable:** `resale_price`
- **Input Features:** Smartphone specifications, brand, model, condition, damage history, accessories, and purchase details
- **Preprocessing:** Numerical feature scaling and categorical feature encoding
- **Model File:** `model.pkl`

The model was trained using a used-phone price prediction dataset. The `market_demand_score` feature is excluded from the model inputs.

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME.git
cd YOUR_REPOSITORY_NAME/Old_Phone_Price_Prediction
```

Replace the placeholders with your GitHub username and repository name.

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

The application will open in your browser, where you can enter smartphone details and receive a resale price prediction.

## Deployment

The application can be deployed using Streamlit Community Cloud by connecting the GitHub repository and selecting `Old_Phone_Price_Prediction/app.py` as the main file.

## Disclaimer

The predicted resale price is an estimate generated by a machine learning model. Actual resale prices may vary depending on the phone's condition, brand, model, location, and market conditions.
